# Telegram Bot для ASEM PODO @ BEAUTY

Бот для записи клиентов через Telegram с интеграцией в Google Form.

## 🚀 Возможности
- FSM для выбора услуги, даты и времени
- Отправка данных в Google Form
- Уведомления администратору
- Webhook для работы на Render
- Health-check для мониторинга
